# Bennett Week

Phone-first rolling 7-day view for Bennett. Seven cards: today plus the next 6 days in America/Chicago.

No login. No chat. No accounts.

## Open it tonight

1. Download this repo (Code → Download ZIP) or clone it.
2. Open `index.html` in a browser. Works on a phone or laptop.
3. Swipe the cards, or use Prev / Next, or tap the dots.

If GitHub Pages is on: https://oborgelt.github.io/bennett-week/

## Data

Seed week is in `week.json`. Later the Parenting bot can replace that file. Do not treat Canvas as the full due list — English often lives in a Google sheet.

v1 is a test. Only the real items from this week are seeded. No invented semester of homework.
